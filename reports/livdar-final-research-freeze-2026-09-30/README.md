# Livdar final research freeze, 2026-09-30

## DO NOT restart keyword research from scratch.
## DO NOT regenerate a new independent candidate universe.
## DO NOT replace this master set unless new evidence is versioned and merged into it.

This folder is the source of truth for Livdar SEO, AEO and GEO research.

Any future research must **add to**, **update**, or **explicitly invalidate** what
is here. It must not create a parallel master. Four separate universes were built
before this one and each reset lost the evidence in the last, which is how an
unmeasured assumption survived three passes and inflated the page ceiling by a
factor of twenty.

To merge new evidence:

1. Add the measured rows to the relevant CSV, keeping the existing columns.
2. Re-run the generator for the file you touched, listed below. Do not hand-edit a
   rollup, because the rollups are generated from the master keyword file and a
   hand edit will be silently overwritten.
3. If a verdict changes, record the old verdict and the reason it changed. Do not
   delete it. Every superseded file in this project is kept with a
   `-superseded-<date>` suffix.

## The status vocabulary in the master keyword file

`LIVE_PRIMARY` `LIVE_SECONDARY` `ESIM` `ENTITY_HEAD` `LISTING_HEAD`
`DURABLE_HEAD` `CANDIDATE_HEAD` `PROMISING` `EXPERIMENT_ONLY` `BLOCKED_DATA`
`BLOCKED_LICENCE` `REJECT`

`EXPERIMENT_ONLY` is the status that carries this pass's main finding. It marks a
keyword with large measured demand whose SERP belongs to someone else, such as
`british museum` at 152,000. Recording those as heads would put unwinnable pages
at the top of the build queue.

## What the dedupe did and did not collapse

11,590 rows in, 7,306 out. Four rungs: exact, normalised on case and whitespace,
same-market semantic, and entity-intent.

It never collapses the same intent across markets, because `kalender 2026` is
333,644 in DE and 146,979 in NL and `things to do in spokane` is 4,000 in us and
60 in gb. It never folds diacritics, because `brueckentage` spelled with the
umlaut measures 1,712 and spelled without it measures 8. It never merges an exonym
with its endonym, because `prag` is 15,000 and `praha` is 20.

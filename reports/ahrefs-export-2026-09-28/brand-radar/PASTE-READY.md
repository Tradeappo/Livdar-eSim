## What to save once each report has run

The brief asks for six things, and all six are report tabs: **mentions**, **share of voice**,
**citations**, **cited sources and pages**, **competitors**, **prompt coverage**. Export each
to `brand-radar/` in this folder with today's date in the filename.

These are a **baseline**: their value is that a later run can be compared against them. A
baseline created after 8 October cannot be compared against anything, which is why this sits
with the deadline items.

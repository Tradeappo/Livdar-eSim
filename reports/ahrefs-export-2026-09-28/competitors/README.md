# Competitors, 2026-09-28

`site-explorer-organic-competitors` for livdar.com, mode=subdomains,
country=us, 2026-09-28: **0 rows**, 50 units.

Organic competitors are computed from shared keyword positions. Livdar holds
one position in Ahrefs' index, for its own brand name, so there is nothing
to share and the set is empty. Keyword gaps and competitor-only keywords are
empty for the same reason: all three are functions of a ranking set that
does not exist yet.

This is worth recording as a fact rather than reaching for it a second time.
Competitor analysis becomes available when Livdar ranks for something, which
is downstream of the pages being reachable at all. The comparative material
that does exist was measured directly and is already in the repository:

- `data/atlas/competitors/markets-2026-09-23.json`
- `data/atlas/competitors/cost-of-living-us-2026-09-23.json`

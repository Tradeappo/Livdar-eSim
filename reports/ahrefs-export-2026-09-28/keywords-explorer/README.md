# Keywords Explorer research, consolidated

Date: 2026-09-28. `research-2026-09-28.tsv`, **44 keywords** across DE, AU, CA, FR and a
multi-country volume breakdown.

This is every Keywords Explorer lookup made during the pre-expiry work, in one file, with the
verdict attached. The verdict column is the point: a volume and a KD on their own have already
misled this project twice, in both directions.

| Verdict | Meaning | Count |
| --- | --- | --- |
| `BUILD` | Volume, difficulty and SERP all support it | 25 |
| `PROSPECT` | Worth it, but a data question is unresolved | 1 |
| `CAUTION` | Real difficulty; do not treat as easy | 7 |
| `REJECT` | Rejected, with the reason recorded | 3 |
| `NOTE` | Kept as a calibration point, not a candidate | 8 |

## The three rejections, and why they are in the file rather than deleted

- **`vollmond`, 162,071 at KD 0.** The largest zero-difficulty term found anywhere in this work,
  and pure astronomical computation. Rejected as off-brand for a cost-of-living and salaries site,
  with no monetization path, and no SERP validation run on it. **Kept so it is not rediscovered in
  six months and mistaken for a missed opportunity.**
- **`zeitumstellung 2026`, 56,833 at KD 8.** Would pass any difficulty filter. The SERP is
  `chip.de` (DR 86), `hamburg.de` (DR 89), `ardalpha.de` (76), the European Commission (97), and
  four news blocks above them. A recurring news cycle, not a reference query.
- **`mondkalender`, 20,287 at KD 30.** Same off-brand reasoning as `vollmond`.

## The 8 `NOTE` rows are a calibration lesson

Next-year keywords systematically understate a family. `victoria public holidays 2027` is
**1,249** while `victoria public holidays 2026` is **19,000**. `ontario holidays 2027` is 664
against 4,400 for 2026. Demand for a year builds through that year.

**Size candidates on current-year terms.** Anyone sizing this family on 2027 volumes in September
2026 would conclude it is roughly fifteen times smaller than it is.

## The one correction this file records

`kalender 2027` (DE, 70,657, KD 2) is marked **BUILD**, which reverses an earlier blanket
rejection of year-calendar head terms. That rejection came from `kalendarz 2026` (PL, 430,000,
KD 2), where a page in the SERP carries 55,463 backlinks. The German SERP has
`kalender-online.com` at **position 3 with DR 10 and URL Rating 0**, and no link-gated incumbent
anywhere on the page. **The rejection was market-specific and had been over-generalised.**

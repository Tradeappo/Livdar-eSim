# Livdar Atlas status, 22 September 2026

## Where the code is

Livdar Atlas lives in this repository, next to the eSIM pages, on livdar.com.
No second repository, no second Vercel project, no proxy. Six route folders
under `app/[lang]/` (cities, staedte, orase, airports, flughaefen,
aeroporturi), the modules in `lib/atlas`, the scripts in `scripts/atlas`, the
data in `data/atlas`.

## The ceiling, with the entity lists that are verified today

- Airports with scheduled service and an IATA code, counted from OurAirports on 22 September: 3,244. Airport family: 3,244 x 3 locales = 9,732 candidates.
- Cities: the GeoNames cities15000 count comes from the first CI ingest. A Wikidata cross check on the same day returns 10,162 city items with at least 15,000 inhabitants and a GeoNames id. With 10,162 cities the two city families give 10,162 x 13 x 3 = 396,318 candidates.
- Total with those lists: about 406,000 candidate combinations, which is the 300,000 order of magnitude the plan asks for. The target is reached at roughly 7,700 cities; it is not a number of pages and never will be. Pages exist only after the funnel.

## Automation in the repository

- `.github/workflows/atlas-ci.yml`: tests, quality gate, Atlas QA, funnel and reconciliation on every push and pull request.
- `.github/workflows/atlas-ingest.yml`: weekly refresh of GeoNames, OurAirports and Wikidata labels, climate per lot on demand, opens a pull request, never publishes.
- `.github/workflows/atlas-monitor.yml`: daily production check of every published Atlas URL plus a sample of eSIM URLs, and a stale data check.
- `scripts/atlas/reconcile.mjs`: finds published pages that no longer pass their gates and, with `--retire`, rolls them back page by page.

## What is not done yet, and why

- Full GeoNames ingest: the dump is not reachable from this environment (no CORS in a browser, no outbound network in the build sandbox). It runs in `atlas-ingest` on the first CI run.
- City guides: they need a country facts source that survives a spot check. Wikidata does not: plugs missing for GB, DE, US, JP, GR, NL, RO, wrong for IT; currency empty for FR, NL, CZ; US official languages listed as ch, es, sm.
- Airport pages: the data is ready in the ingest scripts, the demand is not measured yet.

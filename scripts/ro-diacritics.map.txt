# Romanian diacritic restoration, word by word.
#
# Format: one "plain:corrected" pair per whitespace separated token. Lines
# starting with # are comments. Only words that CHANGE appear here; anything
# absent is left exactly as it is.
#
# Why a table and not a rule: Romanian diacritics are not derivable from the
# stripped form. "data" is both "data" (the date) and "dată" (a time, an
# instance); "tine" is both "tine" (you, after a preposition) and "ține" (holds).
# A rule that rewrote every "t" before "i" would produce wrong Romanian in
# hundreds of places. So every word here was decided one at a time, and the
# genuinely ambiguous ones are NOT in this file at all: they are resolved
# separately, in context, by scripts/ro-ambiguous.mjs.
